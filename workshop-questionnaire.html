What would help you handle everyday pressures at work?

Help choose the topics for future live, interactive wellbeing workshops. This is voluntary and takes about three minutes. Please do not provide names, medical information or personal stories. You can skip any question.

01 Which skills would you most like to develop?

Select up to three.

02 How would you prefer to learn?

Select up to two.

03 Would a live, interactive workshop interest you?

04 What would make it easier to attend?

Select any that apply.

05 Any other practical skill you would like to learn?

Optional. Please avoid personal or sensitive information.

Thank you for helping shape future workshops.No names are requested. This is not a health assessment. Your employer should explain how responses will be collected and handled.
